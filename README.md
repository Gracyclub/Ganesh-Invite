# 🌺 Digital Ganesh Chaturthi Blessings & Greeting Web App

A festive, lightweight, and fully responsive digital blessing web app created to celebrate Ganesh Chaturthi. It offers an interactive temple-like experience with virtual pooja rituals, divine prosperity messages, and dynamic name customization.

---

### ✨ Features
- **Dynamic Name Personalization:** Supports URL query parameters (`?name=YourName`) to auto-generate personalized greetings for family and friends.
- **Interactive Rituals:** Tap-to-ring sacred temple bell with synthesizer audio and tap-to-illuminate divine Diya.
- **Festive Visuals:** Falling marigold & rose flower petals animation with soft golden halo effects.
- **Instant WhatsApp Sharing:** Built-in sharing trigger pre-filled with warm festive wishes.
- **Mobile-First Design:** Optimized for mobile browser viewing and Instagram reel demonstrations.

---

### 🛠️ Built With
- **HTML5**
- **Modern CSS3** (Flexbox, CSS Grid, Glassmorphism, Keyframe Animations)
- **Vanilla JavaScript** (Web Audio API, DOM Manipulation, URLSearchParams)
